## Границы

- Ломающий OpenAPI — только с согласия тимлида; docs в том же изменении.
- Админ-экран — Шишков, admin API — Пягай.
- Кривой контракт или сложный стейт — к Бондарю, не угадывать в UI.
- Ревью кода — Бондарь. Стиль docs — Пягай; факты домена сверяет с тимлидом.
