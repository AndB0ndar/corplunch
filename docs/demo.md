# Демо / защита

Цель: за **8–10 минут** показать полный цикл **CorpLunch** комиссии — продукт целиком и вклад всей команды из трёх человек. Оформление заказа на самом Mealty **не** автоматизируем и на защите не имитируем.

Ниже — связный текст защиты (что говорить) и пошаговый сценарий (что кликать). Реплики можно читать почти дословно; таблица в конце — короткие ответы на типовые вопросы.

## Текст защиты (для комиссии)

### Открытие (≈45 сек)

Добрый день. Мы — команда CorpLunch: **Бондарь** (тимлид, ядро backend и DevOps), **Пягай** (документация, auth/admin API, seed и контрактные тесты), **Шишков** (все экраны React и QA).

Проблема офиса: сотрудники хотят заказывать готовую еду с Mealty, но если каждый действует сам, закупки не видят объём, цены «плывут», а к дате доставки блюдо может подорожать или исчезнуть. CorpLunch разделяет **план** сотрудника (ориентировочная цена) и **заказ дня** закупок (актуальная цена после cutoff). Оплату и корзину на mealty.ru мы сознательно не трогаем: публичного API нет, перенос сводки — руками менеджера.

Стек: FastAPI + PostgreSQL + React/Vite, один Docker Compose. Жизненный цикл — итеративно-инкрементальный (пять поставок за ~9 недель), метод — облегчённый Scrum, код сразу в `main`.

### Кто что сделал (≈30 сек, по желанию комиссии)

| Участник | В продукте на защите |
|----------|----------------------|
| **Бондарь** | Парсер/каталог, cutoff и правило цены, сводка заказов, `GET /api/stats/summary`, Compose |
| **Пягай** | Docs и README под код, login/`/me`, admin users/departments/settings, seed и `sync-from-fixture`, pytest 401/403, CSV/XLSX-рендер |
| **Шишков** | Экраны каталога, плана, сводки, статистики и админки; чек-листы и регресс по этому сценарию |

### Сквозной рассказ по экранам (≈6–7 мин)

1. **Каталог.** Сотрудник видит блюда и цены из локального HTML-снимка Mealty. Второй снимок подготовлен для пересчёта при закрытии приёма.
2. **План.** На дату вперёд сотрудник кладёт 2–3 позиции; второй сотрудник (`employee2`) делает то же — в сводке будут двое. Сумма пока ориентировочная (`price_kopecks`).
3. **Cutoff.** Закупки нажимают «Закрыть приём»: планы фиксируются, каталог переснимается, у позиций появляется `actual_price_kopecks` или `unavailable`. Редактирование плана после cutoff закрыто.
4. **Сводка и экспорт.** Сводка показывает блюда и суммы в рублях, ниже можно раскрыть состав каждого сотрудника. В CSV денежные поля указаны в копейках. Закупки скачивают список и отмечают «Заказ размещён».
5. **Статистика.** Период «с / по», опционально отдел: итог план/факт/дельта, расходы по отделам и сотрудникам, топ блюд, расхождения цен — всё с живого `GET /api/stats/summary`.
6. **Админка.** Создать сотрудника, изменить время закрытия и проверить оба изменения после перезагрузки.

### Закрытие (≈20 сек)

MVP закрывает цикл «план → актуальная цена → сводка → статистика» без автозаказа на Mealty. Дальше — только сопровождение парсера, если витрина сменит вёрстку. Готовы к вопросам.

## Подготовка

Запустить [стенд защиты](../tests/README.md#стенд-защиты) и открыть http://127.0.0.1:5183. Стенд загружает начальный HTML-каталог и читает второй снимок при ручном cutoff. Для прогона выбрать свободную дату доставки начиная с послезавтра по Москве. После репетиции перед следующим показом перезапустить API стенда, чтобы вернуть начальные цены, и выбрать новую свободную дату.

Окна или профили: `employee@kis.local` / `employee`, `employee2@kis.local` / `employee2`, `procurement@kis.local` / `procurement`, `admin@kis.local` / `admin`.

## Сценарий (клики)

### 1. Зачем система (30 сек)

Сказать открытие из блока «Текст защиты». Показать, что это не чат и не Excel, а единый контур плана и закупки.

### 2. Каталог (1 мин)

Войти сотрудником. Категории, цена, карточка. Упомянуть стабильный `external_id` и что сегодня каталог с фикстуры.

### 3. План наперёд (2 мин)

На выбранную дату первый сотрудник сохраняет солянку и котлетки из морепродуктов (680 ₽), второй — одну солянку (270 ₽). Показать обоих в сводке закупок за ту же дату.

### 4. Cutoff и цена (2 мин)

Под закупками нажать «Закрыть приём заказов» и подтвердить. У первого сотрудника план заблокирован, солянка подорожала с 270 до 285 ₽, у котлеток появилась пометка «Нет в меню Mealty».

### 5. Сводка закупок (2 мин)

Показать двух сотрудников. Скачать CSV и открыть его. В файле одна строка блюда с кодом 721, количеством 2 и суммой 57000 копеек. В сводке это 570 ₽. Нажать «Заказ размещён» и подтвердить.

### Как перенести на Mealty (для комиссии / закупок)

1. Скачать список после cutoff («Скачать список для заказа» / Excel).
2. В файле: `external_id`, название, `qty`, цены в копейках.
3. На mealty.ru вручную набрать те же позиции в корзине офиса.
4. Оформить заказ на сайте Mealty; в CorpLunch только «Заказ размещён».

Не показывать логин на Mealty, DevTools с cookie и `/ajax.php`.

### 6. Статистика (1–2 мин)

В статистике указать одну и ту же дату доставки в обоих полях и выбрать отдел «Разработка». Для доступных порций план составляет 540 ₽, факт 570 ₽, дельта +30 ₽. Показать отдел, обоих сотрудников, солянку в топе и 570 ₽ на графике за день.

### 7. Админка и роли команды (30–45 сек)

Войти администратором, создать учебного сотрудника с уникальной почтой, сохранить новое время закрытия. Обновить страницу, показать строку сотрудника и сохранённое время. Вернуть исходное значение cutoff.

### 8. Вопросы комиссии

| Вопрос | Короткий ответ |
|--------|----------------|
| Почему не заказываете через API Mealty? | Публичного API нет; корзину не трогаем — юридически и по robots.txt это уже не витрина. |
| Что если вёрстка сломается? | Селекторы в одном месте у провайдера; CI гоняет HTML-фикстуру, на сайт в тесте не ходим. |
| Как не положить сайт? | 1–2 sync/сутки + квота, кэш, 429 на ручной refresh. |
| Откуда актуальная цена? | После cutoff повторный снимок каталога → `actual_price_kopecks` / `unavailable`. |
| Как добавить Delivery Club? | Новый `FoodProvider`, то же поле `dishes.source`; UI и сводка те же. |
| Кто что делал в команде? | Бондарь — ядро и stats; Пягай — docs, auth/admin, seed, контрактные тесты; Шишков — UI и QA. |
| Почему итерации, а не водопад? | Трое параллельно с первого дня; каждый этап — рабочий инкремент к защите (см. process.md). |

## Что не показывать

Логин на mealty.ru, DevTools с чужими cookie, «парсим ajax.php». Для комиссии достаточно фикстуры, живого compose и этого сценария.
