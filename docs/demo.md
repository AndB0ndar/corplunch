# Демо / защита

Цель: за 8–10 минут показать полный цикл **CorpLunch** без оформления заказа на самом Mealty.

## Подготовка

1. `docker compose up --build`.
2. Если живой парсинг недоступен — загрузить каталог из фикстуры (команда seed/sync-from-fixture, её нужно сделать на этапе 1).
3. Время cutoff для демо можно временно поставить далеко вперёд (например 23:59), чтобы успеть заполнить план, затем вызвать «закрыть день» вручную (кнопка закупок или `POST` cutoff) — не ждать реальных 16:00.

Иметь под рукой три окна браузера (или три профиля): employee, procurement, admin.

## Сценарий

### 1. Зачем система (30 сек)

Это CorpLunch: офис заказывает Милти. Сотрудники планируют заранее, закупки в день поставки видят **актуальную** цену и сводку, а не переписку в чате.

### 2. Каталог (1 мин)

Войти сотрудником. Показать категории, цену, карточку блюда. Сказать, что данные с главной mealty.ru, id стабильный (`external_id`).

### 3. План наперёд (2 мин)

Выбрать **завтра** (или учебную дату). Добавить 2–3 блюда. Показать ориентировочную сумму. Сохранить. Зайти вторым сотрудником (если есть seed) или тем же и поменять qty.

### 4. Cutoff и цена (2 мин)

Переключить роль на закупки (или админ). Запустить sync / «закрыть приём заказов». Вернуться в план сотрудника: поля заблокированы, у одной позиции другая цена (можно подменить в фикстуре) или «нет в меню».

### 5. Сводка закупок (2 мин)

Экран дня: агрегат блюд, сумма, кто заказал. Скачать CSV. Нажать «Заказ размещён». Пояснить: на сайт Mealty менеджер переносит этот список руками.

### 6. Статистика (1–2 мин)

Период неделя: сумма, отделы, топ блюд, столбец план vs факт.

### 7. Вопросы комиссии

| Вопрос | Короткий ответ |
|--------|----------------|
| Почему не заказываете через API Mealty? | Публичного API нет, корзину не трогаем: юридически и по robots.txt это уже не витрина. |
| Что если вёрстка сломается? | Селекторы в одном файле, CI на HTML-фикстуре. |
| Как не положить сайт? | 1–2 sync/сутки, кэш, 429 на ручной refresh. |
| Откуда актуальная цена? | После cutoff повторный снимок каталога → `actual_price`. |
| Как добавить Delivery Club? | Новый `FoodProvider`, то же `dishes.source`. |

## Что не показывать

Логин на mealty.ru, DevTools с чужими cookie, «парсим ajax.php». Для комиссии достаточно фикстуры и скрина витрины.
