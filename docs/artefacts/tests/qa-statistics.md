# QA: статистика периода

Дата: **16.11.2026**. База: `4c8fd8d` + локальные изменения frontend/QA этого задания.

**PASS в проверенном объёме.** Демостатистика приведена к контракту API. Вместо графика по отделам показана таблица — предусмотренный этапом 4 вариант без графика. Новых дефектов реализованной статистики в итоговом прогоне не обнаружено.

## Окружение и границы проверки

- Windows, Edge/Chromium: desktop 1280×720, mobile-эмуляция iPhone 13 390×664. Это не Safari и не физический iPhone.
- Корневой `docker-compose.yml` + `tests/.env.test`, проект `corplunch-tests`, настоящий FastAPI и PostgreSQL, API `18000`, Vite `5182`. Дополнительного Compose нет.
- `tests/seed_stats.py` создал независимые данные через ORM: два отдела, три неактивных сотрудника, два рассчитанных дня и планы в исключаемых статусах. Даты этого прогона: 10–12 января 2040, пустой день 13 января. Так данные не смешиваются с обычным демо. Повторный запуск выбирает свободные даты.
- Браузер обращался к настоящему API без HTTP-подмен. Исходные цены и `unavailable` установлены фикстурой; live-прогон не проверяет получение цен с Mealty или переход cutoff. Серверный тест отдельно проверяет cutoff → сводка → статистика с подменой внешнего провайдера.
- К Mealty эти проверки статистики не обращаются. Backend pytest использует отдельную базу `corplunch_test`. Исходный код backend и контракт API не менялись.
