UI узнаёт о закрытии из `editable` при следующем опросе: 10 секунд плюс время ответа сервера. Запрет сохранения на API действует независимо от этого интервала. Проверка исключения снятых блюд здесь относится к фактической сумме персонального плана; результат для общей сводки закупки не заявляется.

Незакрытых дефектов в проверенных сценариях не обнаружено. В рамках этой работы исправлены остановка опроса при несохранённом плане, скрытое сообщение о закрытии на мобильной вкладке и контраст выбранной вкладки.
