# Парсер каталога Mealty

Публичная главная [https://www.mealty.ru](https://www.mealty.ru). Публичного JSON API нет. Каталог — server-rendered HTML (~230 карточек `.catalog-item`).

Оформление заказа, корзина, `/ajax.php`, `/cabinet`, `/purchase` **не используем**. `robots.txt` их явно закрывает. Парсим только витрину.

## Что снимаем с карточки

Селекторы держим в одном модуле (`app/providers/mealty.py`), чтобы правка вёрстки не расползлась.


| Поле                | Откуда                                                                                                                         |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `external_id`       | `.catalog-item[data-product_id]`                                                                                               |
| `seller_product_id` | `[data-seller-product_id]`                                                                                                     |
| `name`              | `.meal-card__name`                                                                                                             |
| `subtitle`          | `.meal-card__name-note`                                                                                                        |
| `price`             | `.meal-card__price[data-price]`                                                                                                |
| `old_price`         | `.meal-card__price-old`                                                                                                        |
| `weight_g`          | `.meal-card__weight`                                                                                                           |
| КБЖУ                | `.meal-card__proteins`, `__fats`, `__carbohydrates`, `__calories`                                                              |
| описание            | `.meal-card__description`                                                                                                      |
| картинка            | `img` в `.meal-card__image` → абсолютный URL                                                                                   |
| категория           | якоря секций `#breakfast`, `#salad`, `#soup`, `#main_dish`, `#sandwich`, `#dessert`, `#bread`, `#drink`, `#snack` / `#novelty` |


Пример живых id: `data-product_id="875"` — «Картофельные ньокки…», цена в `data-price`.

Цены зависят от **города**. В запросе нужно учитывать выбранный город (по умолчанию Москва): cookie/заголовок так же, как делает сайт, либо отдельный параметр провайдера. Город хранится в `settings.mealty_city`.

## Политика запросов

- User-Agent проекта (учебный, с контактом команды).
- Не чаще 1–2 раз в сутки + ручной sync закупок.
- Таймаут и один retry.
- При 5xx / пустом каталоге — **не** помечаем всё меню unavailable (это ошибка сети, не снятие блюд).
- Успешный ответ с N≥1 карточками: позиции не из ответа → `available=false`.



## Тесты (обязательно)

CI **не** ходит на mealty.ru.

1. Сохранить урезанную фикстуру HTML (2–3 `.catalog-item` с реальными классами) в `backend/tests/fixtures/mealty_catalog.html`.
2. Тест: `parse_html(fixture)` → ожидаемые `external_id`, имя, цена, категория.
3. Тест: блюдо пропало между двумя снимками → во втором `available=false`.
4. Опционально: ручной e2e `pytest -m live` (не в CI).

Если Mealty поменяет вёрстку, падает только парсер-тест — чиним селекторы в одном файле.

## Расширение на другие сайты

Новый класс `OtherProvider` с тем же `FoodProvider`. В `dishes.source` пишем другой ключ. Планы и сводки не знают про HTML.

## Юридическое / учебное

Это учебный парсинг публичной витрины для внутреннего учёта, не перепродажа каталога и не нагрузка на сайт. Не логиниться под чужими аккаунтами Mealty. Не обходить оплату и антибот. Для защиты достаточно фикстуры + скрин текущего меню.
