# Интерфейс (черновик для фронтенда)

Аудитория: сотрудники офиса утром и закупки днём. Не витрина ресторана и не админ-панель «из коробки».

## Характер

Кухня корпоративной поставки: плотная сетка карточек, спокойный тёплый светлый фон бумаги-накладной, акцент — глубокий шалфейно-зелёный (еда / «можно брать»), предупреждения — охра (цена уехала), ошибки наличия — терракотовый. Цифры сумм — табличная гротеск-насечка, названия блюд — чуть более живой гротеск.

Не делать generic SaaS: фиолетовые градиенты, «AI dashboard», огромный hero с процентами.

## Экраны

### Вход

Один столбец: почта, пароль, «Войти». Подсказка демо-учёток только в dev.

### Сотрудник: каталог + план

```
┌──────── header: дата доставки  [◀  ср 16 апр  ▶]  сумма плана  ──── роль
│  фильтры категорий   поиск
│  ┌ карточка ┐ ┌ карточка ┐ ┌ карточка ┐
│  │ фото     │ │          │ │          │
│  │ имя      │ │          │ │   + в план
│  │ 410 ₽    │ └──────────┘ └──────────┘
│  └──────────┘
│  справа (desktop): состав плана, qty, «нет в меню», Сохранить
└────────────────────────────────────────────────────────────────
```

На мобилке план — нижняя шторка / вторая вкладка.

Заблокированный день: кнопки «+» серые, бейдж «Приём закрыт в 16:00».

### Закупки: сводка дня

Таблица блюд сверху (это то, что уйдёт на Mealty), под ней — аккордеон по сотрудникам. Кнопки: «Обновить каталог», «Скачать CSV», «Скачать Excel», «Заказ размещён». Статус заказа — одна строка, не пайплайн из пяти шагов.

### Статистика

Фильтры `с` / `по` / отдел. Сначала итог и дельта план/факт, затем таблица отделов, затем топ блюд. График простой (столбики по дням), без 3D.

## Копирайт

- «План на среду», не «meal_plan draft».
- «Нет в меню Mealty», не «unavailable flag».
- «Скачать список для заказа», не «export office_order_items».
- Ошибка cutoff: «Приём заказов на эту дату закрыт. Изменить состав уже нельзя.»
